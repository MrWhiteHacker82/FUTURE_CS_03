# API Security Risk Analysis

## 📌 About the Project

This project is developed as part of the Future Interns Cyber Security Internship.

The objective of this project is to analyze API security risks, identify insecure endpoints, assess authentication and authorization controls, and identify potential data exposure and input validation issues.

## 🎯 Objectives

- Identify insecure API endpoints
- Analyze authentication and authorization mechanisms
- Check for data exposure risks
- Identify access control issues
- Analyze input validation
- Check for rate-limiting gaps
- Provide security recommendations

## 🛠️ Tools Used

- Postman / Insomnia
- Browser Developer Tools
- Sample Public APIs
- Google Docs / MS Word
- PDF

## 🔍 Key Features

- API endpoint analysis
- Authentication assessment
- Authorization testing
- Access control analysis
- Data exposure identification
- Input validation review
- Rate-limiting analysis
- Security risk documentation

## 📊 Risk Classification

| Risk Level | Description |
|---|---|
| High | Significant security impact requiring priority remediation |
| Medium | Security weakness that should be addressed |
| Low | Lower-impact security issue or improvement |
